# ST Chat Jumper

SillyTavern 悬浮跳转条/轮盘插件，提供快捷楼层导航、快速编辑、翻页、楼层收藏等功能。
> 已兼容TauriTavern（tt 酒馆）

- **快速跳转** — 最近 3 楼 / 快速翻页（左/右）/ 上一楼 / 下一楼（跳到头部）
- **精确对齐** — 当前楼层头部 (H) / 尾部 (L) 对齐
- **跳转/区间显示** — 输入单个楼层号可直接跳转；输入区间仅显示指定范围的楼层
- **快速智能编辑** — 选中文字可高亮定位到编辑器的对应位置；未选中则编辑当前楼层
- **快速删除** — 框选某楼文字后可以通过酒馆确认窗口删除该楼；未框选时默认删除最新楼层
- **快速翻页** — 可以快速在最新楼层里左右翻页/重roll
- **楼层收藏** — 点选收藏楼层，快速跳转到收藏的楼层，可一键跳转查看并添加备注
- **按钮自定义** — 在扩展设置入口打开独立窗口，自定义按钮的显示/隐藏、排列顺序、悬浮栏大小
- **手势快捷轮盘** — 可独立于悬浮条启用，支持鼠标修饰键 + 右键拖动、可配快捷键、触屏长按 / 连击
- **悬浮可拖拽** — 长按悬浮条即可拖动到屏幕任意位置，支持横/竖布局切换

## 按钮自定义

在 SillyTavern / TauriTavern 的 **扩展设置** 中，点击 **ST Chat Jumper 设置卡片**，所有设置在独立窗口编辑：
- **勾选/取消** — 控制每个按钮的显示或隐藏
- **拖拽排序** — 拖动左侧手柄 `⠿`，或点 ↑ / ↓ 调整按钮在悬浮条中的排列顺序
- 设置会自动保存，刷新后保持

## 手势轮盘

默认关闭；开启后可用 `Alt+Shift+J` 呼出。鼠标需单独开启，默认 `Alt + 右键拖动`；未拖动的普通右键保留原生菜单。手机可选长按（原地松手后点选 / 滑选）或连击。轮盘与悬浮条可分别开启或同时使用。主轮盘及各二级轮盘的扇区、标签、顺序和动作均可编辑。

设置窗口提供触发、外观、动作、悬浮条、方案等自定义设置。

## 安装

- 自动安装
打开 SillyTavern → 扩展 → 安装扩展
输入以下url：
```
https://github.com/qianzhuowo/ST-Chat-Jumper
```

- 手动安装
把整个`ST Chat Jumper`文件夹放到：
```text
SillyTavern/public/scripts/extensions/third-party/
```
然后在 SillyTavern 的扩展管理里启用该插件。


### 可配置按钮

| 设置项 | 说明 |
|--------|------|
| 收起/展开 | 悬浮条的折叠/展开切换按钮 |
| 最近第3楼 | 跳转到倒数第 3 条消息 |
| 最近第2楼 | 跳转到倒数第 2 条消息 |
| 最近第1楼 | 跳转到最后一条消息 |
| 快速翻页(右) | 最新楼层的右翻页/重roll |
| 快速翻页(左) | 最新楼层的左翻页 |
| 跳转/区间显示 | 输入楼层号跳转或区间显示/区间翻页/恢复（含导航按钮和指示器） |
| 横/竖布局切换 | 切换悬浮条的横向或纵向排列 |
| 上一楼 | 跳转到上一楼（头部对齐） |
| 下一楼 | 跳转到下一楼（头部对齐） |
| 对齐到头部 (H) | 将当前楼层对齐到视口顶部 |
| 对齐到尾部 (L) | 将当前楼层对齐到视口底部 |
| 快速编辑 (✏️) | 打开/保存快速编辑 |
| 快速删除 (🗑️) | 框选消息文字时删除对应楼层；无选区时删除最新楼层，使用酒馆原生确认窗口 |
| 收藏 (📌) | 收藏楼层功能组（图钉 + 展开箭头） |

## 开发与模块扩展

入口 `index.js` 只负责原生 ES Modules 启动，功能代码位于 `src/`，无需构建或安装运行时依赖。设置、宿主适配、导航/区间、编辑/删除、收藏、UI 与生命周期均有独立模块；存储格式、DOM 和现有宿主兼容契约保持不变。

- [模块边界、状态所有权与扩展指南](docs/modules.md)
- 运行回归与模块集成测试：`npm test`（或 `node --test tests/*.test.cjs`）
