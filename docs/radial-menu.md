# 可配置快捷轮盘

## 使用入口与安全默认

扩展设置 → **ST Chat Jumper 设置卡片**，在独立窗口中编辑全部悬浮条、导航、收藏预览和轮盘设置。点击 ×、窗口外侧或按 Esc 关闭；设置自动保存。旧按钮顺序、显隐、缩放、位置及区间配置保留，无需迁移或重设。按钮排序除拖拽外也有 ↑ / ↓，方便触屏使用。

轮盘默认**关闭**，不改变已有操作习惯。开启轮盘后：

- **快捷键**：默认 `Alt+J`；修饰键与字母/数字可改。在非输入区域呼出后点击选择，或方向键切换、Enter / Space 执行；Backspace 返回主轮盘，Esc / Tab 取消。
- **鼠标**：需单独开启；默认 **Alt + 右键拖动**，超过阈值呼出，滑向按钮后松手执行。可以更换按键、修饰键或取消修饰键。**没有拖动的普通右键不屏蔽原生菜单**，刚执行过手势后的下一次独立右键也不屏蔽。某些浏览器/系统保留中键、侧键或快捷键，未必能交给网页。
- **手机 / 平板**：默认关闭，可选长按或连击。长按激活后可以滑向目标松手执行；原地松手会保留轮盘，随后点选（包含屏幕边缘）。连击按所设次数、间隔及位置范围呼出，再点击选择。未激活前移动超过 10px 直接让给滚动，不阻止正常阅读。
- **区域**：鼠标 / 触屏默认仅聊天区域，可扩大为页面非交互区域；快捷键在页面非输入区域使用，不要求焦点先放到聊天区域。

输入框、可编辑内容、链接、按钮/交互控件、弹窗和插件浮条不接管手势。修饰键精确匹配；额外按住其他修饰键不会误触。连击与长按均为显式启用，建议阅读时优先使用长按、默认聊天区域，不要给常用滑动手势配置无修饰键触发。

> 浏览器对触屏的滚动拥有优先权，可能发送 `pointercancel`。此时轮盘安全取消，不强行锁住页面滚动；若设备不支持可靠的长按滑选，可原地长按松手后点选，或改用连击。CDP 触屏模拟通过不等同于所有 Android / iOS 设备已经实机验证。

## 选择、子轮盘与取消

- 主轮盘可配置 **0–12 个扇区**；二级轮盘最多 16 个，每个有自己的名称、扇区顺序、文字和动作。每个子轮盘都可独立编辑，不共享内容。
- 主轮盘的扇区可指向某个二级轮盘；悬停一段时间自动进入，或松手进入后点选。切换后需要新的移动才能选中子动作，避免父扇区的松手直接误执行子动作。
- 二级轮盘不再递归；返回中心按钮或 Backspace 返回主轮盘。无效、循环和丢失的子菜单引用在配置归一化时移除。
- 空扇区不执行动作。鼠标拖动回到中心死区、超出外甩距离、Esc、Tab、滚动、失焦、窗口尺寸变化、触屏取消或聊天切换均取消。
- 轮心自动夹取到视口内；小视口自动缩小。靠边长按的原地松手按原始触点判断，不受轮心移位影响。
- 已激活的手势会消费释放事件及随后的兼容 click，避免同时触发点选收藏或底层消息控件。

可调参数包含鼠标按键/修饰键、快捷键、触发区域、拖动阈值、长按时间、连击次数与间隔、半径、中心死区、外甩距离和子菜单悬停时间。数值均有安全上下界，无效值恢复默认。

## 分区控制台与可视化编辑

设置窗口按「触发与安全」「外观与形态」「扇区与动作」「悬浮条与导航」「方案与备份」「关于与致谢」分区。桌面使用左侧导航，窄屏变为可横向滑动的顶部导航；方向键也可切换分区。

在动作页点击交互画布上的扇区，会选中对应检查器；在外观页点选也会定位动作编辑。预览本身从不执行动作。可修改标签、自动 / 自定义文本图标、独立文字颜色、插件动作或目标子轮盘；提供4 / 8 / 12方位快速调整、单个添加 / 删除和排序，数量调整可立即撤销。

外观页提供石墨、瓷白、冰川、苔绿四套原创配色和分区圆环、疏朗花瓣、连续圆环三种形态。可调整六类颜色、半径、尺寸比例、中心留白、扇区间隙、旋转、字体、背景不透明度、光晕、标签 / 图标及中心符号。设置窗口自身可以跟随酒馆、清亮浅色或柔和深色。

每个二级轮盘默认继承主外观，也可开启独立覆盖或同步主外观。共享渲染器确保预览与真实轮盘使用同一扇区几何；极小尺寸会联合限制有效取消区和可见内径，保证仍有可选的外环。

### 命名方案与备份

最多保存8套方案，快照包含所有主 / 子轮盘内容、图标、独立外观及基础半径。应用方案不会修改鼠标、键盘或触屏开关。JSON导入支持旧v1和当前v2；默认仅导入内容 / 外观，只有明确勾选后才导入触发设置。导入前做类型、数量、颜色和引用校验，拒绝未来未知版本及超过100万字符的文本，不执行字符串代码。

v1配置读取时自动归一化为v2，保留按钮动作、顺序、子轮盘与手势参数，添加外观默认值；下次用户保存时才写入新格式。若导入含主轮盘局部外观，将其提升到唯一全局主外观，防止编辑对象与实际显示不一致；二级覆盖仍独立保留。

## 与悬浮条的关系

在同一个设置窗口中隐藏 / 显示悬浮条；轮盘有独立启用开关。因此可以只用悬浮条、只用轮盘、两者同时使用或都关闭。悬浮条按钮显隐和顺序**不会限制轮盘动作**。

动作直接调用现有插件服务，不点击或搜索可见 DOM 按钮。导航、快速编辑、区间、点选收藏与收藏管理无需显示悬浮条。布局/收起动作本身只改变悬浮条布局；轮盘中的“最近收藏”会打开独立收藏管理窗口，而不是打开附着于隐藏悬浮条的面板。删除等动作继续使用插件原有宿主确认流程，默认轮盘不包含删除。

## 配置与模块边界

新增配置保存在 `extensionSettings['ST-Chat-Jumper'].radial`，`version: 2`；使用现有 `SillyTavern.getContext().saveSettingsDebounced()`，TT 同样走宿主兼容上下文。其他字段和 localStorage 的旧位置/缩放格式不变。宿主存储暂不可用时仅使用本会话内存回退，不写入别的宿主或浏览器存储。未知 provider 的 `{type, id}` 会保留，但未注册时拒绝执行并提示。

| 模块 | 职责 |
|---|---|
| `radial-config.js` | 默认配置、纯归一化、二级引用校验、兼容存储 |
| `action-registry.js` | 动作注册、列举和分发，内置 plugin provider |
| `radial-view.js` | 独立极坐标 / SVG 扇区视图、共享预览、有效内径计算 |
| `radial.js` | 几何命中、视口布局、轮盘状态机、输入和监听器清理 |
| `radial-settings.js` | 轮盘配置、菜单/扇区编辑和收藏预览方式 |
| `settings-ui.js` | 独立原生 dialog、扩展设置入口、原有设置控件 |

均使用现有 `createFeature` / `requiredServices` 显式服务注入，生命周期由 application、toolbar、lifecycle 管理；销毁移除全局监听、定时器、轮盘及设置窗口，热重载不重复挂载。

未来接入酒馆操作、角色卡或自定义命令时，新增 provider 并通过 `registerShortcutAction({ type, id, label, execute })` 注册。`type` 用独立命名空间，`execute` 自行检查宿主能力、权限和用户确认；卸载时调用注册函数返回的注销函数。配置存储的只有引用，不执行任意字符串、`eval` 或从配置构造脚本。尚未实现的 provider 不伪装成可执行选项。

## 验证

- `npm test`：原有 40 项 + 17 项轮盘 / 外观测试，覆盖安全默认、归一化、存储共存、命中/边缘、原生右键、输入排除、取消/清理、快捷键、子菜单、触屏滚动/长按/连击、释放消费和动作注册。
- `node tests/radial-runtime.cjs <CDP端口> <报告路径> [--tt]`：真实 ST 静态服务或 TT WebView；使用可信 CDP 鼠标、键盘、触屏输入。TT 只在网络响应中临时提供工作区 JS/CSS，**不改 TT 源码或部署目录**。测试使用自定义无副作用动作，恢复设置，不执行消息删除/编辑/生成。
- 结果与已知限制见 [轮盘验证记录](radial-validation.md)。
